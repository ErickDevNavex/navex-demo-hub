# 🚀 Navex Demo Hub

**Portfólio interativo de demonstrações** — Todas as ferramentas Navex em um só lugar.

> Hub 100% estático (HTML/CSS/JS) com demos de alta fidelidade para apresentações comerciais. Sem backend, sem banco de dados, dados totalmente fictícios.

## 🏗️ Estrutura

```
├── navex-hub-portfolio-v1.html   # Hub principal (landing page)
├── Demos_Hub/                    # Demos interativas (HTML estático)
│   ├── autosac.html
│   ├── logistech.html
│   ├── datainsight.html
│   └── ...
├── Sistemas/                     # Código-fonte dos sistemas originais (referência)

└── PROGRESS_LOG.md               # Log de progresso
```

## 🎨 Design System

- **Dark mode** com glassmorphism premium
- Tipografia moderna (Inter)
- Micro-animações e transições suaves
- Totalmente responsivo

## 🚀 Como Usar

1. Clone o repositório
2. Abra `navex-hub-portfolio-v1 (1).html` no navegador
3. Navegue pelas demos clicando nos cards

> Nenhuma instalação necessária — é tudo HTML/CSS/JS estático.
