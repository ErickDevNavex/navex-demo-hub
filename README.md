# Navex Demo Hub

Portfolio interativo de demonstracoes dos sistemas Navex.

Hub 100% estatico em HTML, CSS e JavaScript, preparado para deploy no Coolify via Dockerfile e Nginx.

## Deploy

- Build pack: Dockerfile
- Porta interna: 80
- Dominio sugerido: https://hub.comercial.navex.ia.br

## Como usar localmente

Abra `navex-hub-portfolio-v1 (1).html` no navegador.
